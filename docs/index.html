No model runs here

An @mention is a distributed system with a three-second front door.

Slack retries any event it thinks you dropped, reusing the same event id. A slow handler therefore produces duplicate work, not a timeout. Split the system at that deadline and the rest follows: what you can no longer do synchronously becomes a queue, and what a queue makes affordable is a team of agents rather than one prompt.

Five nodes on the common path. Two of them run no model at all, and this page records the arguments that got them there.

One mention, end to end

Everything below ack happens after Slack has already been told 200 OK. Throughout: solid teal is implemented and tested in the repo, dashed violet is designed but not built, amber is a service outside our boundary.

How much machinery a question gets

Two tiers. A third — a "direct" tier for questions the thread already answers — was deleted once the librarian became code, because it was then just the writer, and a tool-calling model handed the thread simply answers without calling a tool. Same single call. Debate is the only real escalation, and it engages where the mechanical verifier is structurally blind.

The triggers are the complement of what the verifier can check.

It checks tokens, so it is blind to causation — a causal question escalates. It checks what is said, never what is done, so it is blind to writes — a non-auto tool escalates. That is a boundary rather than a heuristic, which is why the predicate is twelve lines of code and not a model call.

Who owns which decision

One decision each, and the interesting number is not eleven. Four of these run no model at all, and two are designs rather than code. Open any card for the system prompt it is actually sent — the same string the simulator assembles, from the same array.

The verifier

The one place a second model was replaced by forty-five lines of code. A model reading the same context inherits the first one's misreadings — one that misread 41/s as the baseline will confirm 41/s as the baseline. A set-difference cannot.

It advertises its own biggest hole.

Right tokens, wrong relationship: evidence says 41/s at 15:01, the draft says 41/s at 14:01 — both present, the pairing invented, and it passes. Fixing that needs span-level evidence binding, which is not forty-five lines. A verifier claiming completeness would be the falsely-verified-code failure this repo has already hit five times.

Memory is a security boundary

Scope comes from the channel the event arrived in, never from anything in the message body — in a public channel the body is attacker-controlled.

The filter belongs in the query predicate, never after retrieval.

Post-filtering leaks through result counts, ranking and latency, and sits one refactor from deletion by someone who reads it as a redundant guard. Run Scope boundary in the simulator: the excluded count is shown, and the hits are absent from the result set rather than removed from it.

Reaching a tool, and reaching an agent

MCP is a typed call into a capability inside your trust boundary: the agent never holds a credential, and the allowlist is set membership at dispatch. A2A is a task handed to something with its own goals and lifecycle — it can decline, it can pause to ask you a question, and it can outlive the worker that started it. A specialist that returns in four seconds should have been a tool, and an earlier review was right to demote one that did.

There is no slack.post_message, and that is the most important row in the table.

Posting is a graph edge that runs after the verifier, fenced by db.reserve_post(). As a tool it would hand the agent a path around the verifier, and a gate that can be bypassed is not a gate. The build fails if it ever appears — along with any irreversible write whose policy is auto.
